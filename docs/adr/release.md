# ADR 0009 — Стабилизация и первый выпуск

[Release gate](../release.md) · [Core](../core.md)

Статус: решения вошли в опубликованную версию `v0.1.0` (`1ffd150`). Изменения не расширяют прикладную функциональность и не меняют утверждённые публичные сигнатуры.

| Решение кандидата | Мотивация |
|---|---|
| Recovery внутри `coordinator.call`, безопасная ошибка с фазой/именем | Panic callback не отменяет rollback и cleanup остальных участников; panic value не попадает в ошибки |
| Проверять предел RPC header size с запасом net/http | Исключить integer overflow при конфигурации; согласовать с Management |
| Совместные smoke tests полного графа, всех трёх RPC протоколов, событий, jobs, ORM, telemetry и rollback | Изолированные тесты модулей не проверяют DI/lifecycle взаимодействие |
| Release gate с Go 1.27.x (актуальный патч), govulncheck и двумя живыми зависимостями | Воспроизводимая проверка; отсутствие CI не считать успешным CI |
| Обновлять зависимости реальным `go get`/tidy/verify, без ручной генерации хэшей | Обнаружены advisory для старых версий; локальный Go proxy недоступен. Конкретные версии и scan описаны в release gate |
| Первый планируемый тег `v0.1.0` только после проверок | Не выдавать кандидат или частичные проверки за готовый релиз |

Panic в самом Open требует локальной очистки; произвольная goroutine или прямой Fx hook не охватываются recovery. Таймауты не обещают принудительную остановку прикладного кода. Ошибки callback (не panic) по-прежнему должны быть безопасны для логирования. Достижимость advisory, совместимость нового module graph, браузерная и внешняя интеграция и поведение под нагрузкой требуют проверок; результаты настоящего CI пока отсутствуют. Тег и merge остаются за владельцем.
